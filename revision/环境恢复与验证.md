## 以后迁移或恢复

建议备份整个返修目录，尤其是 `revision/environment_assets/`。其中保存了本机编译的 Mamba wheel、源码包和构建记录，并附 SHA256 清单。该 wheel 针对当前 Linux/Python 3.10/PyTorch 2.6/CUDA 12/SM86 组合构建，不应直接用于其他 ABI 或 GPU 架构。

```bash
# 已安装 Conda，且当前目录为返修项目根目录时：
conda create -n fsrnet_recovered --file revision/conda-explicit.lock.txt
conda run -n fsrnet_recovered python -m pip install -r revision/requirements.runtime.lock.txt
conda run -n fsrnet_recovered python -m pip install --no-deps revision/environment_assets/mamba_ssm-2.2.5-*.whl
conda env config vars set -n fsrnet_recovered PYTHONUTF8=1
```

`requirements.runtime.lock.txt` 特意不包含 Mamba 的本机绝对路径引用；Mamba 必须用附带 wheel 安装，避免再次取得不兼容的预编译包。安装清单面向已验证的去雾网络和评估路径；未额外安装该路径不使用的可选 causal-conv1d 加速扩展。

PSNR/SSIM 无需网络权重。LPIPS 的 AlexNet 权重缓存位于 `~/.cache/torch/hub/checkpoints/`，pyiqa 校准权重位于 `~/.cache/torch/hub/pyiqa/`；迁移时可一起备份，否则首次运行需要下载。数据目录按新机器位置修改，预检通过后再开始训练。
